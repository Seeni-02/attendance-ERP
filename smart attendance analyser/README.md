# smart attendance analyser 
The Attendance Analyser is a secure and scalable attendance management system designed for colleges and academic departments. The system allows faculty members to record daily attendance digitally and automatically calculates each student’s attendance percentage based on real-time data. Instead of relying on manually entered working days, the system dynamically calculates attendance using actual recorded sessions, ensuring accuracy and eliminating calculation errors.  A key feature of the project is its real-time SMS notification system. When a student is marked absent, an automatic SMS alert is sent to the parent, improving communication, transparency, and accountability. The system supports large student databases, making it suitable for institutions with thousands of students.  The application is designed as a private desktop-based solution, ensuring data security within the institution’s network. With admin login authentication, structured data storage, and automated reporting, the project provides a practical, real-world solution to modernize attendance tracking in educational institutions.
